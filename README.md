# GrammarGuru 🎯

GrammarGuru is an interactive English grammar game that helps users improve their grammar through sentence challenges and explanations.

## Features
- Interactive grammar questions
- Multiple difficulty levels
- Instant answer feedback and explanations
- Score and progress tracking
- Review incorrect answers
- Multiple grammar topics

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Start playing and improve your grammar!

## Purpose
This project was created to make English grammar learning simple, interactive, and enjoyable.
